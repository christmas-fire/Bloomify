# Bloomify
Bloomify - это REST API сервис на Go, имитирующий backend цветочного магазина.

## Функционал
- **Авторизация/Аутентификация пользователей**:
  - Регистрация нового пользователя.
  - Аутентификация и авторизация с использованием JWT токена.
  
- **CRUD операции с сущностями пользователей и цветов**:
  - Создание, просмотр, обновление и удаление цветов.
  - Поиск цветов по имени, описанию, цене и наличию.
  - CRUD операции для пользователей.

- **Мониторинг и логирование**:
    - Сбор метрик с помощью Prometheus.
    - Централизованный сбор логов с помощью Loki и Promtail.
    - Визуализация данных в Grafana.

## Технологический стек
- **Go** - основной язык программирования.
- **PostgreSQL** - основная база данных.
- **Docker & Docker Compose** - для контейнеризации и управления сервисами.
- **Prometheus, Loki, Grafana** - для мониторинга и логирования.
- **NocoDB** - для простого доступа к базе данных через UI.
- **Swagger** - для документирования API.

## Запуск проекта
Для запуска проекта необходимо иметь установленный [Docker](https://www.docker.com/) и [Task](https://taskfile.dev/).

1.  **Клонируйте репозиторий**:
    ```bash
    git clone https://github.com/christmas-fire/Bloomify.git
    cd Bloomify
    ```

2.  **Создайте `.env` файл** в корне проекта, скопировав `.env.example` (если он есть) и заполнив необходимые переменные окружения.

3.  **Запустите приложение**:
    ```bash
    task up
    ```
    Эта команда соберет Docker-образы и запустит все сервисы в фоновом режиме.

## Доступные команды
```bash
task: Available tasks for this project:
* clean:         Остановить, удалить контейнеры, сети и тома данных.
* default:       Показывает доступные задачи.
* down:          Остановить и удалить контейнеры.
* logs:          Показать логи всех сервисов.
* ps:            Показать статус контейнеров.
* start:         Запустить существующие контейнеры (без пересборки).
* stop:          Остановить запущенные сервисы.
* swag:          Сгенерировать документацию Swagger UI.
* up:            Собрать образы и запустить все сервисы в фоновом режиме.
```

## Документация
Документация API доступна по ссылке [interactive Swagger documentation](http://localhost:${BACKEND_PORT}/swagger/index.html#/) после запуска приложения.
